## 1. Problem Statement

Traffic congestion is a persistent challenge in dense urban areas. It is difficult to study traffic flow directly because road users have different characteristics and driving behaviours, while traffic signals influence vehicle queues and movement.

Agent-based modelling provides a way to investigate these interactions through simulated scenarios.

**Research questions:**

- How do vehicle composition and traffic-light timing affect simulated traffic flow on a road in Georgetown, Penang?
- How does average traffic speed change as vehicle density increases?

**Study site:** A multi-lane road segment approximately 1.04 km long in Greenlane, Georgetown, Penang, with a traffic signal at one end. The road network was prepared using OpenStreetMap data.

Because measured traffic data was unavailable for this study, the analysis uses simulated traffic data rather than real-world traffic observations.

## 4. Methodology

### 4.1. Agent-Based Traffic Simulation

The model represents a road network along which vehicle agents travel towards destinations or move according to the model's wandering behaviour.

Vehicle agents have individual behavioural parameters governing movement, acceleration, speed, and lane changing. Traffic-light agents switch between red and green according to configured timing parameters.

Each simulation runs for **1,000 cycles**, with **five repeated runs per scenario** to account for randomness in the model.

Two simulation scenarios were analysed:

- **Scenario 1:** peak hour traffic
- **Scenario 2:** off-peak hour traffic

### 4.2. Simulation Data

Each simulation run produces a CSV file. Each row represents a road segment at a particular simulation cycle, recording average vehicle speed and vehicle counts, including totals and counts by vehicle category.

| File pattern | Description |
|---|---|
| `tlB_1.csv` to `tlB_5.csv` | Raw output for Scenario 1, runs 1–5 |
| `tlB2_1.csv` to `tlB2_5.csv` | Raw output for Scenario 2, runs 1–5 |
| `new_*.csv` | Processed per-cycle results generated by the analysis notebooks |

The CSV files contain simulated outputs from the model, not observed traffic measurements.
